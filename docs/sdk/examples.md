# Examples

## TypeScript Node.js Example

### Complete Client Code

```typescript
// examples/node-ts-example/index.ts
import { ZerisClient, ProofBuilder } from '@zeris/sdk';
import { Connection, clusterApiUrl, Keypair } from '@solana/web3.js';
import * as fs from 'fs';

async function main() {
    // Setup connection
    const connection = new Connection(clusterApiUrl('devnet'));

    // Load keypair
    const keypairData = JSON.parse(fs.readFileSync('keypair.json', 'utf8'));
    const keypair = Keypair.fromSecretKey(new Uint8Array(keypairData));

    // Initialize client
    const client = new ZerisClient(connection);
    const proofBuilder = client.getProofBuilder();

    // Load proof from file (generated by snarkjs)
    const proofJson = JSON.parse(fs.readFileSync('proof.json', 'utf8'));
    const proofData = proofBuilder.buildProofFromJson(proofJson);

    console.log('Submitting proof...');

    try {
        // Submit proof
        const signature = await client.submitProof(keypair, proofData);
        console.log('Proof submitted successfully!');
        console.log('Transaction signature:', signature);

        // Listen for verification event
        await client.listenForEvents((event) => {
            console.log('Event received:', event);
        });

        // Get updated state
        const state = await client.getZerisState();
        console.log('Current Merkle Root:', Buffer.from(state.merkleRoot).toString('hex'));
        console.log('Total proofs:', state.proofCount);

    } catch (error) {
        console.error('Error:', error);
        process.exit(1);
    }
}

main();
```

## Rust Example

### Complete Verifier Client

```rust
// examples/rust-example/src/main.rs
use zeris_sdk::{ZerisClient, ProofData};
use solana_sdk::signature::{Keypair, Signer};
use std::fs;
use serde_json;

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    // Load keypair
    let keypair_data: Vec<u8> = serde_json::from_str(
        &fs::read_to_string("keypair.json")?
    )?;
    let keypair = Keypair::from_bytes(&keypair_data)?;

    // Initialize client
    let client = ZerisClient::new("https://api.devnet.solana.com");

    // Load proof data
    let proof_json: serde_json::Value = serde_json::from_str(
        &fs::read_to_string("proof.json")?
    )?;

    // Parse proof (simplified - in practice, properly parse Groth16 proof)
    let proof_data = ProofData {
        proof: vec![], // Parse from proof_json
        public_signals: vec![], // Parse from proof_json
    };

    println!("Submitting proof...");

    // Submit proof
    match client.submit_proof(&keypair, &proof_data) {
        Ok(signature) => {
            println!("Proof submitted successfully!");
            println!("Transaction signature: {}", signature);

            // Get state
            let state = client.get_zeris_state()?;
            println!("Current Merkle Root: {:?}", state.merkle_root);
            println!("Total proofs: {}", state.proof_count);
        }
        Err(e) => {
            eprintln!("Error submitting proof: {}", e);
            std::process::exit(1);
        }
    }

    Ok(())
}
```

## End-to-End Integration

### 1. Generate Proof (using snarkjs)

```bash
# Create circuit
echo 'pragma circom 2.0.0;
template Multiplier() {
    signal input a;
    signal input b;
    signal output c;
    c <== a * b;
}
component main = Multiplier();' > circuit.circom

# Compile
circom circuit.circom --wasm --r1cs

# Setup (simplified - use proper ceremony in production)
snarkjs groth16 setup circuit.r1cs pot12_final.ptau circuit_0000.zkey
snarkjs zkey contribute circuit_0000.zkey circuit_0001.zkey --name="1st Contributor"
snarkjs zkey export verificationkey circuit_0001.zkey verification_key.json

# Generate proof
snarkjs groth16 prove circuit_0001.zkey witness.wtns proof.json public.json
```

## Advanced Examples

### Batch Proof Submission

```typescript
async function submitBatchProofs(proofs: ProofData[]) {
    const signatures = [];

    for (const proof of proofs) {
        const sig = await client.submitProof(keypair, proof);
        signatures.push(sig);

        // Wait for confirmation
        await connection.confirmTransaction(sig);
    }

    return signatures;
}
```

### Real-time Event Monitoring

```typescript
async function monitorProofs() {
    await client.listenForEvents((event) => {
        switch (event.type) {
            case 'ProofSubmitted':
                console.log(`New proof from ${event.submitter}`);
                break;
            case 'ProofVerified':
                console.log(`Proof ${event.proofHash} verified: ${event.isValid}`);
                break;
            case 'MerkleRootUpdated':
                console.log(`Merkle root updated to ${event.newRoot}`);
                break;
        }
    });
}
```

### High-Speed Batch Verification

```rust
async fn batch_verify_proofs(proof_hashes: Vec<[u8; 32]>) -> Result<(), Box<dyn std::error::Error>> {
    let client = Arc::new(ZerisClient::new(rpc_url));

    let tasks: Vec<_> = proof_hashes.into_iter()
        .map(|hash| {
            let client = Arc::clone(&client);
            tokio::spawn(async move {
                client.verify_proof(&hash)
            })
        })
        .collect();

    for task in tasks {
        task.await??;
    }

    Ok(())
}
```
